Decompose The input is represented as a sum of rectangular pulse components.
Respond separately Each pulse produces its own first-order response yₖ(t).
Add the responses For a linear system, the sum of component responses equals the response to the summed input.
This is the key bridge to convolution: y(t) ≈ Σ yₖ(t). As Δt → 0, the rectangular-pulse sum will lead naturally to an impulse-response weighted sum and then to the convolution integral.
