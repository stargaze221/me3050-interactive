Two Ways to Build a Signal

A linear system becomes easier to understand when a complicated signal is built from simple pieces. Two especially useful choices are localized impulses and exponential components.

same signal  →  different building blocks  →  different but equivalent system descriptions

The big picture first

Both viewpoints use the same linearity idea: break the input into simple pieces, analyze each piece, and add the responses.

Localized in time: shifted impulses

u(t) ≈ Σ u(tk) Δt δ(t−tk)
↓ LTI system
δ(t−τ) → h(t−τ)
↓ continuous superposition
y(t) = u(t) * h(t)

Structured by exponential behavior

u(t) ≈ Σ ak eskt
↓ LTI system
est → H(s)est
↓ transform representation
Y(s) = H(s)U(s)
Goal for this lecture: understand why these two descriptions are connected by the Laplace transform, and why convolution in time becomes multiplication in the s-domain.

Explore the two building-block viewpoints

Sample a smooth signal at many time locations. Each sample supplies the weight of one localized piece. As the cells get narrower, the sum approaches the original signal.

The same idea can be written with complex exponentials: f(t) ≈ Σ ckejkω0t. Fourier series uses discrete harmonic frequencies.

Fourier transform extends the harmonic idea from discrete frequencies to a continuum. Laplace then extends the kernel from purely oscillatory e−jωt to complex exponential e−(σ+jω)t.

Useful viewpoint: along a fixed σ, the Laplace transform is Fourier-like analysis of the exponentially weighted signal f(t)e−σt. The full Laplace transform is more general than the Fourier transform because s can move away from the imaginary axis.

Keep this idea: an integral is a continuous sum. Linearity lets us add the responses of the pieces. The next step is to use the impulse decomposition to derive convolution, and then see why the Laplace transform turns that convolution into multiplication.
