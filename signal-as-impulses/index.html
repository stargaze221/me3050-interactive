Signal as Weighted Impulses Explorer

Break a continuous-time signal into many small time cells. Each cell can be represented by a shifted unit-area impulse approximation, weighted by the signal value and the cell width. As the cells become smaller, the sum approaches the original signal.

x(t) ≈ Σ x(τk) Δτ δΔτ(t − τk)   →   x(t) = ∫ x(τ) δ(t − τ) dτ

What the limit means

1

Partition time

Make Δτ smaller by increasing N. Each cell contributes one local sample of the signal.

2

Weight each impulse

The kth impulse has signed area x(τk)Δτ. Positive and negative signal values give positive and negative weights.

3

Take the limit

As Δτ → 0, the Riemann sum becomes an integral over all shift locations τ.

Key idea: the delta function is acting like a continuous-time “selector.” The identity x(t) = ∫ x(τ) δ(t−τ) dτ says that a signal can be viewed as a continuous superposition of shifted impulses, each weighted by the signal value at that shift.

Bridge to convolution

For an LTI system, each shifted impulse δ(t−τ) produces a shifted impulse response h(t−τ). Therefore each tiny input contribution becomes a tiny output contribution:

x(τ) δ(t−τ) dτ  →  x(τ) h(t−τ) dτ

Adding all output contributions gives y(t) = ∫ x(τ) h(t−τ) dτ.
