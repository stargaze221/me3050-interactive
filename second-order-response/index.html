2. Pole locations

The same ωn and ζ that shape the time response also place the poles in the s-plane.

Characteristic equation
s² + 2ζωns + ωn² = 0

3. Read the parameters physically

ωn

Natural frequency sets the time scale

With ζ held fixed, larger ωn moves the poles farther from the origin and makes the response faster.

ζ

Damping ratio sets the response character

Low ζ allows oscillation and overshoot. ζ = 1 is critical damping. ζ > 1 gives a nonoscillatory overdamped response.

K

Gain sets the final scale

For a constant step input, the steady-state output is yss = KU₀.

Try this sequence
  1. Fix ωn and move ζ from 0.2 to 1.5.
  2. Fix ζ = 0.5 and double ωn.
  3. Watch both the time response and the poles move.

4. Damping regimes at a glance

ζ = 0UndampedSustained oscillation; poles on the imaginary axis.
0 < ζ < 1UnderdampedDecaying oscillation; complex-conjugate poles.
ζ = 1Critically dampedFastest nonoscillatory return for this standard form.
ζ > 1OverdampedTwo real negative poles; slower nonoscillatory response.
