2. What does the time constant mean?

The transient error decays exponentially. After each time constant, only about 36.8% of the previous error remains.

Gain sets the scale

Time constant sets the speed

A larger τ gives a slower response. A smaller τ gives a faster response.

Initial condition sets the transient

The initial condition changes the starting point, but a stable first-order system still approaches the same steady state.
